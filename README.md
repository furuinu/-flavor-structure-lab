# FLAVOR STRUCTURE LAB β — 味覚構造体ジェネレーター v0.9

味覚を、質量・骨格・動き・色面・触感の関係から生成するWebGL/Canvas対応の実験的な3D Webアプリです。

## アプリ

GitHub Pages: https://furuinu.github.io/-flavor-structure-lab/

*アプリの公開ソースは `index.html` です。JavaScriptと初期の6列×81行パレットを内蔵しており、CDNなしで動作します。*

## v0.4 新機能

- 各パーツに独立した **2種類のモーション** をシードで選択（16種類の運動から組み合わせ）。脈動、自転、伸縮、波動、破裂風変位、融解風変位、粘着風の横滑り、折込、微振動、ねじれ、収縮、浮遊、伝播、渦流、凝固風変位、分岐風の変形。
- **停止／再生、時間リセット、速度・変形強度** の調整。アニメーションはWebGL頂点シェーダーで実行します。WebGLに対応しない端末では軽量なCanvas変形表示へ切り替わります（Canvasでは質感と運動を簡略化します）。
- 左右の色面ごとに**16種類の表面表現**から割り当て。ノイズとパターンを使った石粒、絹面、綿毛、鏡面、マット、繊維、砂、亀裂、陶肌、ゴム、毛羽、濡れ肌、炭化、結晶、金属刷毛、粉末。光沢/凹凸感は実物のマテリアルを完全再現したものではなく、リアルタイムシェーダーによる視覚的近似です。
- **グラデーション**による色境界の滑らかな混合。ユーザーが幅を調整できます（変更時は同じシードで再メッシュ化）。
- **24の形状系統**。大きなマスと骨格だけでなく、プリズム、円柱、円錐、多面体、積層、細胞状、折込、結晶などを追加。プリミティブ中心の形は低確率で選択します。
- **約60の味覚・運動キーワード**から4〜7個選択し、造形傾向とモーション設定に反映。任意のテーマ（リズム/重量/陰陽/折込/融解など）を指定することもできます。

## パレット抽出ルール

元画像の6列×81行から、各生成で**異なる2行**を乱数抽出し、それぞれの行から**重複しない3列**を乱数抽出します。左3色・右3色の合計6サンプルです。元画像に同じRGB値があれば、抽出された色が一致する可能性があります。

生成時に左右の形、中央関係、材質、動き、カメラ初期値などを独立した乱数系列から決定します。シードと同じUI設定、同じパレット、同じ再生時間で再現できます。

## 操作

1. 「完全ランダム生成」→新しいシードで作品を生成。
2. オブジェクトをドラッグ→回転。ピンチ/ホイール→ズーム。
3. 「⏸ 一時停止」「▶ 再生」でモーションを停止/再開。「時間リセット」で0秒へ。
4. モーション速度、運動強度、質感強調、色面グラデーションを調整。
5. キーワードの生成テーマを変更した場合、同じシードで設定だけを変更して再計算。
6. PNG / 設定 JSON / お気に入り保存。お気に入りは端末のブラウザ内のみ保持します。JSON再読み込みは未実装です。

## 技術上の制約

- **破裂・融解・粘着**はリアルタイムの頂点変位による表現です。毎フレーム真のトポロジー破壊/流体シミュレーションを行うものではありません。
- WebGL対応機種ではGPU変形とフラグメントテクスチャ、非対応環境は軽量Canvasレンダリングです。Canvas表示は厚みのソートや陰影・テクスチャが限定されます。
- 高度な一体メッシュのブーリアン再構築、GLB/OBJ出力、アニメーションの動画書き出しは未実装です。
- バッテリー・発熱への配慮として、モバイル画面ではWebGL解像度を下げ、OSの「視差効果を減らす」設定が有効な場合は一時停止状態から始まります。

## v0.7：陰影とフラット表示の個別設定

- **陰影を有効にする**：ONで光源由来の立体陰影・光沢・リムライトを表示、OFFでライティングを除去したフラット表示。
- **陰影の強さ（0〜200％）**：陰影ONの場合のみ作用し、100％は従来相当。0％ではライティング寄与がなく、200％は陰影を強調します。トグルOFF時はスライダー無効。
- **フラット表示ではテクスチャも消す**：陰影OFF時のみ有効。ONにするとテクスチャ模様・バンプ・光沢・発光を除去し、補間された色面とグラデーションだけで表示します。OFFなら表面模様を維持します。
- これらの表示設定は形状・動き・カラーパレット抽出結果を変更せず、描画にのみ適用されます。設定JSONには `shadingEnabled`、`shadingStrength`、`flatTextureOff` を保存します。JSONの読み込み機能は未実装です。
- WebGLではピクセル単位、Canvas代替表示では近似表現です。陰影OFF/テクスチャOFF時のCanvasは元色面の三角形平均色で描画します。

## v0.8：ポリゴン欠落・描画の継ぎ目の修正

- **原因**：Canvas代替表示では、再生中に三角形を数枚おきに間引いて描画していました。これは描画負荷の軽減策でしたが、連続している面にも穴を作っていました。
- **対策**：三角形単位の描画スキップを廃止し、生成された全ポリゴンを描画します。ソフトウェア描画時は形状生成時のSDF解像度を適度に落とすことで描画負荷を調整します。
- Canvasのアンチエイリアシングで現れる細い継ぎ目も、各面をわずかに広げて塗ることで目立ちにくくしました。
- WebGL表示の三角形数とCanvas表示の三角形数は異なります。同じシード・端末・描画方式なら形状と運動は再現可能です。
- 個別に生成される梁、リボン、膜、破片などは意図的に別部位のままです。すべてが単一の完全結合メッシュになるものではありません。

## v0.9：Canvasスムーズシェーディング

- `index.html` はGitHub Pagesの `main` / `/(root)` にそのまま置ける単一HTMLファイルです。ビルドや外部ライブラリは不要です。
- **Canvas表示の陰影ON時**：ポリゴンごとの単色塗りから、頂点の色と照明係数を補間する分割描画（Gouraud風の近似）へ変更。色や陰影の三角形境界が目立ちにくくなるよう改修しました。
- 隣接する面の細い隙間が表示されにくいよう、拡張した下地ポリゴンを先に描画します。
- 陰影OFF時は従来どおりフラット表示を維持し、テクスチャも消す設定も有効です。
- **注意**：Canvasによる近似補間はGPUのピクセル単位のスムーズシェーディングと完全には同等ではありません。交差・独立する部位間には境界が残ります。表示負荷は端末やポリゴン数によって変わります。

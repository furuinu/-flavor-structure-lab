# FLAVOR STRUCTURE LAB β — 味覚構造体 / 味覚生命体ジェネレーター v1.3

味覚や香りを、**質量・骨格・色面・触感・運動**として立体化する、完全オフライン動作の実験的3D Webアプリです。  
通常の**味覚構造体モード**に加え、ロールシャッハ的な左右対称性をもつ**味覚生命体モード**を搭載しています。

## アプリ

GitHub Pages: https://furuinu.github.io/-flavor-structure-lab/

- 公開用ソースは **`index.html`** です。
- 外部CDNやビルド工程は不要です。
- GitHub Pages では **`main` / `/(root)`** に `index.html` を置くだけで動作します。

## 現在の主な機能

### 1. 配色ルール
- 元パレット画像の **異なる2行** をランダム選択
- 各行から **重複しない3色** をランダム選択
- 合計 **6色（左3色 + 右3色）** を生成に使用

### 2. 味覚構造体モード
- 大型の塊、骨格、板、棘、リボン、膜、細胞状構造などをランダム生成
- 左右の独立形状が中央で融合、接合、圧縮、重合
- 回転、収縮、拡散、融解、破裂風などの複合運動

### 3. 味覚生命体モード
- 左右対称ベースの**人工生命体**を生成
- 古生代 / カンブリア紀 / 高分子模型 / 細胞 / 微生物を思わせる曖昧な生体造形
- 中央核、膜、繊毛、触手、節足的器官、胞子房、群体構造などを生成
- 「生物」「器官」「分子」「微生物」の**解釈の余地**を残す設計

### 4. 生命体専用パラメータ
- **生命体の系統**
  - 自動
  - 古生物 / カンブリア
  - 高分子 / 分子模型
  - 細胞 / 微生物
  - 節足 / 殻 / 触手
  - 膜 / 葉状 / ローブ
- **左右対称性**
- **解釈の余地 / 曖昧さ**

### 5. 生命体クイックプリセット
- 古生物標本
- 高分子胞体
- 微生物群体
- 繊毛浮遊体
- 節足奇体
- ランダム生命体

### 6. モーション
- 各パーツに独立した複合運動を割り当て
- 回転強度・IK風屈曲強度を調整可能
- 既存プリセット
  - 完全ランダム
  - 有機・呼吸
  - 機械・軸回転
  - 粘性・融解
  - 繊細・静寂
  - 活発・破裂
- 生命体専用プリセット
  - **生命体・呼吸**
  - **生命体・繊毛**
  - **生命体・節運動**

### 7. 表示・質感
- 陰影 ON/OFF
- 陰影の強さ調整
- フラット表示時のテクスチャ除去
- Canvas代替描画でも継ぎ目を目立ちにくく補正
- Canvas代替描画ではスムーズシェーディング寄りの表示

### 8. 保存
- PNG保存
- **PNG書き出し倍率 1× / 2× / 3× / 4×**
- 設定JSON保存
- お気に入り保存
- 再現リンク作成

## 使い方

1. `完全ランダム生成` で新しいシードを生成
2. 必要に応じて `生成プロファイル` を **味覚生命体** に変更
3. 生命体系統・左右対称性・曖昧さを調整
4. クイックプリセットを押して方向性を素早く変更
5. ドラッグで回転、ホイール / ピンチでズーム
6. モーションプリセットや陰影設定を調整
7. `画像 PNG` で保存

## GitHub Pages 公開手順

### 最小構成
公開に必要なのは基本的に以下だけです。

- `index.html`
- `README.md`（任意）
- `original_palette.png`（参照用、任意）

### 手順
1. GitHub リポジトリのルートに `index.html` を配置
2. **Settings → Pages** を開く
3. `Deploy from a branch` を選択
4. Branch を **`main`**、Folder を **`/(root)`** に設定
5. Save
6. 数分待つと GitHub Pages URL で公開

## 技術上の注意

- 破裂、融解、粘着などは物理シミュレーションではなく、頂点変位による視覚表現です。
- IKは厳密な逆運動学ソルバーではなく、部分変形の近似です。
- WebGLが使えない環境ではCanvas代替描画になります。
- JSONの再読み込み機能は未実装です。
- GLB / OBJ / 動画出力は未実装です。

# FLAVOR STRUCTURE LAB β — 味覚構造体ジェネレーター

味覚を、質量・骨格・色彩・素材・運動として可視化するジェネラティブ3D Webアプリです。

**公開アプリ:** https://furuinu.github.io/-flavor-structure-lab/

## v0.2 で追加した機能

- 左右の造形を24系統から独立生成。プリミティブ形状は低確率で登場。
- 16種類の運動モード（脈動、回転、伸縮、破裂、融解、粘着、収縮、浮遊など）をパーツ単位で組み合わせ。
- アニメーションの再生・一時停止、速度、強度の調整。
- 色面の境界をグラデーションで補間。
- 色面ごとに16種類の質感候補（石粒、絹面、綿毛、鏡面、無光沢、繊維、砂粒、亀裂、陶肌、ゴム、毛羽立ち、濡れ肌、炭化、結晶、金属刷毛、粉末）。
- リズム、重量感、陰陽、テンポ、展開、折込などのキーワードを生成ルールに反映。

## 維持している基本仕様

- 既定のカラーパレット **6列 × 81行** から毎回別々の2行を選択。それぞれの行から重複しない3列を選んで左3色＋右3色の6色を抽出。
- 左右の構造体が中央で融合、貫入、接合、巻き付き、嵌合・重合などの関係を作る。
- シード値による再生成、ドラッグ回転、拡大縮小、PNGと設定JSONの書き出し。
- WebGLが利用できないブラウザではCanvasによる軽量描画に切り替え。

## 使い方

Safari、Chromeなどから公開アプリを開き、**完全ランダム生成**を押します。パラメータ、テーマ、速度、動きの強度を変更できます。同じシードと同じ条件を入力すると生成形状を再現できます（動的アニメーションの時間位置は再生状況に依存）。

静的配信方式なのでビルドは不要です。GitHub Pagesは `main` ブランチの `/(root)` から配信します。ローカルでは `index.html` を開くだけでも使用できます。

## 試作版の制限

高品質な物理ベースレンダリング、液体トポロジーの連続的な組み換え、GLB/OBJでの3D書き出し、アニメーション動画出力は未実装です。多くの動きはパーツの変形として表現しています。WebGL性能は端末に依存します。

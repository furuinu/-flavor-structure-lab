# FLAVOR STRUCTURE LAB β — MORPHOGENESIS ENGINE β2

公開デモ: https://furuinu.github.io/-flavor-structure-lab/

「生物には見えるが、すべて似た形に収束する」という課題に対して、従来の共通胴体エンジンを置き換えた形態生成の公開試作版です。

## 6つの独立した成長文法

| 形態系統 | 主要な成長則 | 支配的なシルエット |
|---|---|---|
| 葉状分岐 | 自己相似分岐・葉脈の成長 | 枝葉が展開する羽枝 |
| 分節形態 | 体節の逐次加成 | 節列と反復的な側葉 |
| 群体・出芽 | 母房と子房の親子接合 | 不等大の房が増殖した群体 |
| 管束・空洞 | 開いた管の伸長・分岐 | 中空を示す多数の管 |
| 放射殻・透かし網 | 放射格子・複層の殻 | 空隙のある円盤や籠 |
| 高分子・結合網 | ノードと架橋の成長 | 鎖・ループ・三次元ネット |

各系統には3つのサブプランがあり、合計18通りの形態骨格を用意しています。元パレットの **異なる2行×各3列** の抽出則を維持します。

## 操作

- **異なる生命体を生成**: 前回とは別の系統を優先した新規シード
- **この系統で変異**: 同系統内の個体差を生成
- **6種のサムネイル**: 同じシードの異系統を比較
- **変異強度 / 器官密度 / 対称性・規則性**
- **感覚の重みづけ**: 発生パラメータへの確率的なバイアス
- **ドラッグ・ホイール・ピンチ**: 三次元の座標系で作られた形態を回転・拡大
- **PNG書き出しと再現リンク**

## 技術上の制約

- 外部ライブラリを使用しない、単一HTMLの試作です。
- 現在の描画は **Canvas 2Dへの3D座標投影** であり、厳密な閉じた三次元メッシュ、完全な貫通トポロジー、流体力学・物理シミュレーションを実装したものではありません。
- 見た目は古生物・微生物・高分子を参考にした**創作上の形態**です。化石生物の科学的復元を意味しません。
- 現段階は**6系統の造形文法の可視化**に限定しています。研究統合仕様 v2.0で検討した16系統・反応拡散・進化探索・MAP-Elitesは今後の実装対象です。
- 同一シード・同一設定・同一エンジン版で形態を再生成できます。
